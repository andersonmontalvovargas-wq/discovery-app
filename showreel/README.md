# FlowChat AI — Motion Design Showreel

20-second vertical (1080×1920, 60 fps) motion graphics reel on **AI-powered WhatsApp
marketing automation**. Built entirely in code: a deterministic Canvas 2D animation
(`index.html`, every frame is a pure function of time) rendered frame-by-frame with
headless Chromium, plus a soundtrack synthesized with NumPy (`audio.py`, 120 BPM) whose
hits line up with every scene cut.

| Time | Section | Skills shown |
|---|---|---|
| 0–2s | MOTION DESIGN | Kinetic typography, shockwaves, RGB-split glitch |
| 2–5s | Inteligencia Artificial | 3D particle sphere, HUD rings, data callouts, terminal typing |
| 5–9s | Chatbots con IA 24/7 | WhatsApp-style UI animation, product card, tap ripple, scroll |
| 9–13s | Automatización | Flow builder: Meta Ads → chat → AI → sale, animated connectors |
| 13–16.5s | Resultados | Data viz: gauge, counters, bars + line chart |
| 16.5–20s | Automatiza. Conversa. Vende. | Beat-synced kinetic words, logo reveal |

## Preview / build

- Live preview: open `index.html` in a browser (`index.html?t=7.2` freezes a frame).
- Full build: `./build.sh` (needs Node + Playwright, Python 3 + numpy/scipy, ffmpeg).

FlowChat AI is a fictional brand made for this reel.
